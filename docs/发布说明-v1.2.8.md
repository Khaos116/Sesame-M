# 芝麻粒-M v1.2.8

本次汇总自 v1.2.1 以来的更新，包含上游功能同步、任务与领奖修复、多账号隔离和界面体验改进。

## 森林与合种

- 新增「种树攻略｜场景任务」，支持完成子任务并领取已完成任务的奖励；单次失败不再直接加入黑名单。
- 修复保护罩自动续用判断，按主页实际到期时间判断是否需要续用，并补充背包永久卡的使用路径。
- 活力值权益列表改为查询全部 5 个分类并自动翻页，修复权益显示不全。
- 修复真爱合种反复浇水，完善组队合种当日额度记账、模式切换与恢复；临时故障保留重试机会，异常应答不误记额度。
- 修复好友浇水部分失败后可能重复扣能量的问题。

## 庄园与爱心鸡结号

- 更新爱心鸡结号 S2 周活动，支持领取竞赛任务奖励、定量捐蛋和周日结算前定时偷榜。
- 偷榜新增「捐献上限」，0 表示不限；爱心蛋不足以超过榜首或所需数量超过上限时跳过。
- 修复活动轮次中的重复捐蛋记账；活动期间捐蛋走 S2 项目，非活动期间才执行公益捐蛋，异常时避免重复消耗。
- 修复美食及其他道具奖励领取，未知奖励类型不再中断整轮，任务结束时补查补领本轮新完成的奖励。
- 修复满饲料槽时小额道具奖励被错误拦截和库存记账不准的问题；美食领取日志显示实际数量。

## 芭芭农场

- 新增「抽抽乐（阿肥寻宝记）」自动任务、抽奖及任务黑名单配置。
- 完善一键施肥 5 次，修复配置次数小于 200 时未启用批量施肥的问题，并支持 199 次后批量到 204 次的边界处理。
- 修复施肥受限判断：单次或一键 5 次仅增加最低进度时，当天停止该场景施肥；进度回退不误记受限，缺少有效进度时停止本轮。
- 保留按场景配置施肥次数。

## 会员与运动

- 黄金票补齐签到、收取、任务处理和提取／兑换黄金功能，修复签到与收取失败，以及异常数据误判完成的问题。
- 芝麻粒任务补齐领取、反馈、提交链路，以服务端回读的完成度判定结果；修复日志显示完成但任务未完成、每轮重复上报的问题。
- 芝麻粒任务支持复用同一任务尚未完成的记录，多天任务按进度处理；回读数据异常时不误报完成、不误加自动黑名单。
- 运动任务增加 5～9 秒随机间隔，降低连续高频请求。

## 多账号与任务稳定性

- 首页统计、好友统计和自动拉黑记录改为按账号分别保存，切号后重新加载，修复账号间数据混用。
- 修复切号后旧任务等待、重试仍可能发请求的问题；完善停止任务、主任务排期和并发调度，减少重复执行与排期断链。
- 自动白名单不再删除用户手动加入的黑名单条目。
- 备用完成接口增加交易任务过滤，避免自动触发下单、支付、购买等操作。
- 补充异常应答字段和类型校验，减少服务端缺字段或结构变化造成的错误执行。

## 界面与日志

- 修复首页统计需要退出重进才能刷新的问题，返回首页或切换账号后刷新数据。
- 状态栏显示当前执行模块、本轮收取能量和当日收取能量。
- 配置字段页新增搜索；选填编辑页增加全选、反选和取消选择，并完善次数范围校验。
- 好友统计页新增搜索和更清晰的记录展示。
- 运行日志按模块标记，主要记录执行过程；收取、领奖、兑换等结果进入对应的森林／庄园／金豆／其他分类日志。
- 拼图截图移到 `.nomedia/puzzle/<账号名>/`，旧目录自动迁移，避免图片出现在相册中。
- 修复拼图纹理扫描超时后的错误兜底拖动；识别不可信时停止自动拖动，扩充真实截图回归样本。
- 异常统计补充错误码与描述，便于定位失败原因。

## 配置保存与兼容

- 修复配置保存可能覆盖未知字段、丢失其他进程修改，以及配置读取失败后误写默认值的问题。
- 每次覆盖配置前保存同目录的 `config_v2.prev.json` 即时快照，按天滚动备份也改为在写入前执行。
- 修复时间类配置按错误单位截断、未修改却提示保存成功，以及恢复默认配置时的异常。
- 加强 HTTP 接口令牌校验，未配置令牌时拒绝请求。
- 继续保留 GeminiAI 及原有类型、令牌配置。

## 升级说明

- 安装包为 **arm64-v8a 正式版**，沿用原签名。
- 升级后重启支付宝；修改配置后用返回键退出页面保存。
- **旧版混合统计不自动迁移到某个账号**：原文件保留，各账号的新统计从零开始，不影响已有业务配置。
- 新增的场景任务、农场抽抽乐、黄金票签到／收取和提取／兑换默认关闭，请按需开启。
- 爱心鸡结号配置已调整，请重新核对自动捐蛋、偷榜开关及数量／上限。
- 查询收取、领奖等结果时，请打开对应分类日志；使用 HTTP 接口时需配置令牌。
