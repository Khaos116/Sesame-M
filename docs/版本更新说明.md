# 芝麻粒-M 版本更新说明

按版本从新到旧记录用户可见的更新和升级说明。每次发布时在最上方新增版本段落，保留已有版本记录；各版本内容可直接用于 GitHub Release。

## v1.2.11（2026-10-07）

本版汇总1.2.10正式包之后的功能追加及本轮阶段1～65移植。主要参考AG、Xu源码，Sen new、SJ等APK反编译及相关官方公开前端，逐项接入M现有账号、配置和任务机制；准确来源与每项范围见[功能移植来源记录](功能移植来源记录.md)。

### 2026-10-07上游追加（源码）

- 合并MIUIX-api102的12个新提交：修复森林金球重复统计，补动物、过期能量和打地鼠统计；能量雨识别已映射游戏的通用任务类型。
- 普通自动捐蛋改为每日处理、优先S2，未发请求时可回退公益；请求结果未知当天不再重复消耗。保留M排位预算、动态美食及独立偷榜策略。
- 会员游戏中心更新任务目录及待领宝箱领取，修复摇钱树场景施肥，减少已签到、已打卡和已领取任务的重复请求；运动任务命中1009后当天停止。
- 合种未知响应保留当天标记/额度，避免改配置后重发；商城清单成功取到商品后当日不再定期全量拉取。
- 本次源码通过70项隔离回归和Debug Java/Kotlin编译；下文已归档的171441 APK为合并前构建，尚不包含这批更新。

### 蚂蚁森林与合种

- N倍卡支持高倍率替换和临期强制替换，保留有效期保护，使用后确认生效。
- 新增最近30天漏签补签、指定好友收能量白名单、小号复活能量模式及小球例外。
- 补齐找能量预曝光、结束上报、提示后的奖励检查，以及能量雨收尾后的补查。
- 新增独立找能量与扫榜周期、时光加速器自动使用和定点/禁止时段，修正受影响的蹲点任务。
- 智能双击卡按未来蹲点球数量触发，支持永久/31天库存和确认续用；指定道具缺货时可按勾选列表及预算补兑。新增临期库存集中使用，按类型和日上限处理。
- 新增合种队长召唤指定队友。此前AG追加的动物到期替换、好友分档浇水、保护证书兑换和会员绿植浇水一并纳入本版。

### 蚂蚁庄园、家庭与捐蛋

- NPC雇佣支持黄金鸡、农场小鸡和芝麻大表鸽，补满产领取/重雇、炼金资格和持久待收流程，避免遣返仍有奖励的NPC。
- 加速卡每日次数上限可配置，默认8次，-1不限、0不用；动态美食按库存分批使用，并可按捐蛋目标补食、重新读取排名。
- 满仓道具可按已开启的策略先用一张再领奖，覆盖新蛋、加速、篱笆、加饭、公仔、蹭饭、救济及三等级装扮卡，保留库存、效果和次数检查。
- 家庭顶梁柱新增“今日亲密值最低”策略，资料不完整时退回原随机策略；分享新增仅邀请/不邀请选中好友，原不邀请名单仍优先，每轮最多2人，已尝试好友当天不重复。
- 新增捐蛋日/周预算、稳定排名规划及日榜持续追榜，未知捐献只查询、不重复提交。S2周日偷榜可设目标名次1～100，默认1；已达目标、缺目标行或超出资源/预算时停止。日榜继续采用原稳定星级策略。
- 此前追加的篱笆卡、公仔补签和小鸡日记点赞一并纳入本版。

### 会员、账单与资源兑换

- 新增账单贴纸领取、免费升级及奖励/抽奖，接入账单积木世界的任务和奖励流程。
- 新增已开通商家的签到、开门打卡和积分任务，修复MORE后续查询的服务端编号透传。
- 会员积分支持GMT+8定时抢兑和关键词补充权益目录，仍需勾选商品及设置纯积分预算。
- 新增芝麻信用成就馆领取、芝麻粒独立商品目录与勾选兑换，和会员积分、安心豆分别记账。
- 新增蚂蚁保可领保障金与明确浏览任务；安心豆分别支持签到/守护者等级奖、持久订单浏览、每日一次抽奖、保险知识闯关及权益目录。
- 安心豆权益兑换从黄金票扩展到符合相同条件的选中原生纯豆权益：现金为0、无需下单、无外跳。兑换前保存回执和预算，之后核对同权益详情、历史计数及余额扣减；未知结果跨日/重启不自动重复。现金、券、实物和下单类只展示。

### 余额宝体验金

- 新增签到、已完成奖励、任务目录与勾选浏览任务，合并主/促销入口的同任务别名，补主入口报名状态分流。
- 接入全量券转换、指定活动兑换、指定或按预算激活已有体验金资产，以及本轮兑换券直接激活。普通资产旧激活回执可通过两次稳定状态查询恢复确认，不重发激活。
- **开通、开户、转账、付款、充值、购买、签约等任务明确排除**。标题、分类或操作元数据匹配即跳过，勾选、浏览标签、报名状态和已完成奖励列表均不能绕过；执行前重查出现此类信息也停止。
- 兑换券缺少独立终态查询时，只记录接口受理金额及计划日期，保留回执，不将受理写成收益到账。

### 芝麻树、炼金与其他活动

- 接入芝麻树浏览/领奖/净化、芝麻租赁免费浏览和树委托；当前明确BROWSER任务按真实要求完整等待并重新核对合同后发送，签到单独处理。
- 炼金补浏览、免费广告、时段/次日奖励、四款已映射游戏、明确游戏时长、普通频道浮球及P2E页面会话/分片上报，按实际时长等待、核对同记录进度。
- 百次立减卡支持签到、待领奖、明确选定任务及报名、自动选择、完整等待、发送/领奖和预算中断后的待领奖续跑。
- 花花卡支持免费翻卡/合卡及当前任务报名、上报和逐项领奖。接口受理与独立确认分开记录，未确认回执不自动重发。
- 新增好家缴费金签到、明确浏览任务及可领奖励，沿用选定任务和每日预算限制。

### 种花、海洋与公益

- 新增种花大作战动态授权与签到、昨日施肥奖、云朵/虫害及其他免费奖励、收豆、浇水和到期预约、加工厂、抽奖、任务和加速卡。
- 种花支持指定口令/UID助力、外部口令池和独立可选上传；外部地址默认空，上传默认关闭，结果未确认时保留回执。
- 海洋支持推荐好友航行和清理后赠送碎片，遵守好友名单及次数上限。
- 新增动物竞猜两个入口的签到和当前局查询，不投注；新增3小时公益捐步，动态登录、核对可捐步数及前后进度，每天最多一次。

### 运行工具与稳定性

- 各类别“立即执行”按钮文字与内边距缩小，标题行上下各留8dp间距，避免紧贴上下配置卡片。

- 配置页能量雨、打地鼠等快捷子动作按钮改为横向排列，间距8dp，窄屏自动换行；庄园和鱼塘快捷按钮采用相同排布，快捷按钮区与下方配置卡片之间留16dp间距。
- 配置页支持按模块立即执行，以及森林、庄园和鱼塘的指定子动作；与主任务互斥，遵守原账号、开关和消费策略。
- 新增默认关闭的定时支付宝缓存维护，按文件年龄和遍历上限处理，保留目录、链接及新文件。
- 新流程统一保留切号、GMT+8跨日和取消检查；关键写请求单次发送，未知结果保留回执，避免重复消费。日志区分接口受理、状态回查及实际生效。
- 保留GeminiAI及原有配置。无纸阅读和农场游戏时长继续使用M已有实现，本版未改为极速上报。

### 升级与范围

- 版本号为**1.2.11**，保持arm64-v8a、API102和原签名配置。覆盖安装后重启支付宝；配置修改后用返回键退出保存，保留原账号配置。
- 大部分新增开关默认关闭，资源消费预算默认为0；按需开启并勾选目标。家庭默认随机/原分享行为，S2目标默认1，加速卡默认8次，已有设置优先。
- 按用户要求，不再扩展WebDAV的ZIP/自动同步/远端清理，既有手动实现保留。其他商家/未知游戏、无明确执行合同的任务及XR后台云控/JS/批量好友平台跳过；主动移除的旧业务不恢复。
- 本地隔离回归不等于真实账号领奖或资源到账，新增业务效果以支付宝实际状态为准。详细范围、默认值和来源见[使用说明](使用说明.md)、[配置项说明](配置项说明.md)和[功能移植来源记录](功能移植来源记录.md)。
