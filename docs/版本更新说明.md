# 芝麻粒-M 版本更新说明

按版本从新到旧记录用户可见的更新和升级说明。每次发布时在最上方新增版本段落，保留已有版本记录；各版本内容可直接用于 GitHub Release。

## v1.2.10（2026-10-06）

本次发布汇总 **1.2.8～1.2.10** 的功能和修复，并包含最新的农场抽抽乐增强、庄园自动喂鸡重查。版本号继续使用 **1.2.10**，沿用原签名；以下内容可直接用于新 APK 的发布说明。

**本次开发追加（正式包待重打）**：参考 AG 补充以下功能，版本号保持 1.2.10；此前归档的正式 APK 尚不包含本段新增内容，新接口效果待实机验证。

- 森林：动物伙伴工作到期自动替换和派遣二次确认；好友可单独设置 10／18／33／66g 浇水档位，保留原次数及当天剩余额度。
- 森林：新增当前保护地地图的证书自动兑换、会员绿植自动浇水，均默认关闭；兑换回查持有数量，浇水回查水滴和进度。
- 庄园：新增篱笆卡自动使用、数字公仔补签和补签顺序、小鸡日记点赞范围，均默认关闭；效果仍在或结果未确认时避免重复消耗道具。
- 农场：随「农场任务」接入努力流星独立任务、宫格访问、淘宝浏览及新版广告浏览事件；保留用户黑名单，缺少执行依据或进度未推进时说明原因并停止。
- 新功能补充运行日志中的成功、失败及跳过原因，异常响应不直接算完成。

### 蚂蚁森林

- 新增「无纸阅读」，自动获取授权并换取 Token，处理免费书籍、回读能量进度；默认开启，保留已保存的开关值。
- 阅读不再受单轮 30 章限制，有持续能量增长就继续至服务端满额；兼容进度的合法数字字符串，修复授权成功后首次查询即停止的问题。
- 保留无增长、章节循环、接口异常、没有免费书等停止条件；单轮约 15 分钟后暂停，未满额可在下一轮继续。日志显示进度、成功或失败原因，授权失败时提供操作指引，不输出 Token 或授权码。
- 新增「种树攻略｜场景任务」，完成子任务并领取已完成奖励；单次失败不再直接拉黑。
- 修复保护罩续用判断，补充背包永久卡的使用路径；活力值权益支持全部 5 个分类和分页查询。
- 完善真爱合种的当日额度、模式切换和恢复，修复重复浇水、异常误记完成及好友浇水失败后重复扣能量的问题。

### 芭芭农场

- 新增「农场乐园｜完成游戏时长任务」，按服务端要求等待、上报并尝试结项；默认开启，保留已保存的开关值。日志记录执行阶段、结果和失败原因。
- 新增并增强「抽抽乐（阿肥寻宝记）」，兼容新旧活动和任务结构，支持任务处理、领奖及黑名单配置。
- 抽抽乐对已支持的小游戏上报后回查任务状态，未支持或状态未推进时说明原因并跳过；按有效剩余次数批量抽奖，不再逐次抽到 30 次就停止。批量失败后结束本轮场景，不追加单抽，避免重复消耗。
- 完善一键施肥 5 次和边界处理，保留按场景配置次数；进度异常时停止本轮，确认受限时停止当天该场景施肥，进度回退不误记受限。

### 蚂蚁庄园

- 自动喂鸡遇到状态未恢复、查询失败或进食时间异常时，每隔 30 秒重查，连续最多 5 次；恢复后重新安排蹲点投喂，达到上限后等待下一轮。日志记录原因、次数、恢复和停止结果。
- 更新爱心鸡结号 S2 周活动，支持竞赛任务奖励、定量捐蛋和周日结算前定时偷榜；偷榜增加「捐献上限」，0 表示不限。
- 修复活动中的重复捐蛋记账；活动期间走 S2 项目，非活动期间才执行公益捐蛋，异常时避免重复消耗。
- 修复美食及道具奖励领取、小额奖励被满槽错误拦截和库存记账不准的问题；未知奖励类型不再中断整轮，任务结束时补查补领，美食日志显示实际数量。
- 「加饭卡｜使用」仍默认关闭，保留已有配置；此次喂鸡重查不会使用加饭卡。

### 会员与运动

- 黄金票补齐签到、收取、任务和提取／兑换黄金，修复失败及异常数据误判完成的问题。
- 芝麻粒任务补齐领取、反馈、提交及回读确认，复用未完成记录并按进度处理多天任务，减少重复上报；异常回读不误报完成、不误加黑名单。
- 运动任务增加 5～9 秒随机间隔，减少连续高频请求。

### 多账号、配置与任务稳定性

- 首页统计、好友统计和自动黑名单按账号分别保存，切号后重新加载，修复账号间数据混用；自动白名单保留手动设置的黑名单。
- 完善旧任务取消、主任务排期及并发调度，减少切号后旧任务继续请求、重复执行和排期断链。
- 修复配置保存覆盖未知字段、丢失其他进程修改或读取失败后误写默认值的问题；写入前保存即时快照及按天备份。
- 修复时间配置单位、恢复默认配置及保存提示异常；修复搜索前后开关显示不一致，状态跟随实际配置字段。
- 对已确认失效的主完成接口精确跳过，保留备用完成和领奖；繁忙失败按任务和账号短暂退避，避免扩大封禁范围。
- 备用接口过滤交易任务；补充异常应答校验，HTTP 接口未配置令牌时拒绝请求。继续保留 GeminiAI 和原有类型、令牌配置。

### 界面、日志与拼图

- 首页返回或切号后刷新统计；状态栏显示执行模块、本轮及当日收取能量。
- 配置页和好友统计支持搜索，选填编辑页增加全选、反选、取消选择及次数范围校验。
- 运行日志按模块标记，关键收取、领奖、兑换结果保留分类日志；新增功能补充成功、失败步骤和原因，异常统计补充错误码与描述。
- 拼图截图改存 `.nomedia/puzzle/` 下并迁移旧目录，避免进入相册；修复扫描超时后的错误兜底拖动，识别不可信时停止，扩充真实截图回归样本。

### 升级说明

- 安装包为 **arm64-v8a 正式版 1.2.10**，不带排查后缀，沿用原签名，可覆盖安装；安装后重启支付宝，配置修改后用返回键退出保存。
- 阅读和农场游戏时长默认开启，但不会覆盖已保存的关闭状态。农场抽抽乐、种树场景任务、黄金票签到／收取及提取／兑换默认关闭，按需开启；喂鸡重查沿用「投喂小鸡」开关。
- 阅读首次使用先在支付宝打开对应小程序（appId=`2021003114652763`），完成正常登录／授权；无需手动填写 Token。运行日志搜索「无纸阅读」「农场游戏时长」「农场抽抽乐」或「自动喂鸡」查看结果。
- 爱心鸡结号请核对自动捐蛋、偷榜数量及上限。旧版混合统计文件保留，不自动归入某个账号，新统计按账号分别累计；使用 HTTP 接口需配置令牌。
- 收取、领奖等详细结果查看对应分类日志。阅读与农场游戏时长已有用户反馈正常；本次抽抽乐增强和喂鸡重查通过离线回归，实际任务推进、到账和投喂仍以实机结果为准。

此前正式包对应代码通过完整 22 项本地回归、Debug 编译、Release/R8 与原签名校验。本次 AG 开发追加通过完整 23 项本地回归及最终 Debug Java/Kotlin 编译，尚未重打正式包；新功能效果待实机验证。

## v1.2.8（2026-10-05）

本次汇总自 v1.2.1 以来的更新，包含上游功能同步、任务与领奖修复、多账号隔离和界面体验改进。

### 森林与合种

- 新增「种树攻略｜场景任务」，支持完成子任务并领取已完成任务的奖励；单次失败不再直接加入黑名单。
- 修复保护罩自动续用判断，按主页实际到期时间判断是否需要续用，并补充背包永久卡的使用路径。
- 活力值权益列表改为查询全部 5 个分类并自动翻页，修复权益显示不全。
- 修复真爱合种反复浇水，完善组队合种当日额度记账、模式切换与恢复；临时故障保留重试机会，异常应答不误记额度。
- 修复好友浇水部分失败后可能重复扣能量的问题。

### 庄园与爱心鸡结号

- 更新爱心鸡结号 S2 周活动，支持领取竞赛任务奖励、定量捐蛋和周日结算前定时偷榜。
- 偷榜新增「捐献上限」，0 表示不限；爱心蛋不足以超过榜首或所需数量超过上限时跳过。
- 修复活动轮次中的重复捐蛋记账；活动期间捐蛋走 S2 项目，非活动期间才执行公益捐蛋，异常时避免重复消耗。
- 修复美食及其他道具奖励领取，未知奖励类型不再中断整轮，任务结束时补查补领本轮新完成的奖励。
- 修复满饲料槽时小额道具奖励被错误拦截和库存记账不准的问题；美食领取日志显示实际数量。

### 芭芭农场

- 新增「抽抽乐（阿肥寻宝记）」自动任务、抽奖及任务黑名单配置。
- 完善一键施肥 5 次，修复配置次数小于 200 时未启用批量施肥的问题，并支持 199 次后批量到 204 次的边界处理。
- 修复施肥受限判断：单次或一键 5 次仅增加最低进度时，当天停止该场景施肥；进度回退不误记受限，缺少有效进度时停止本轮。
- 保留按场景配置施肥次数。

### 会员与运动

- 黄金票补齐签到、收取、任务处理和提取／兑换黄金功能，修复签到与收取失败，以及异常数据误判完成的问题。
- 芝麻粒任务补齐领取、反馈、提交链路，以服务端回读的完成度判定结果；修复日志显示完成但任务未完成、每轮重复上报的问题。
- 芝麻粒任务支持复用同一任务尚未完成的记录，多天任务按进度处理；回读数据异常时不误报完成、不误加自动黑名单。
- 运动任务增加 5～9 秒随机间隔，降低连续高频请求。

### 多账号与任务稳定性

- 首页统计、好友统计和自动拉黑记录改为按账号分别保存，切号后重新加载，修复账号间数据混用。
- 修复切号后旧任务等待、重试仍可能发请求的问题；完善停止任务、主任务排期和并发调度，减少重复执行与排期断链。
- 自动白名单不再删除用户手动加入的黑名单条目。
- 备用完成接口增加交易任务过滤，避免自动触发下单、支付、购买等操作。
- 补充异常应答字段和类型校验，减少服务端缺字段或结构变化造成的错误执行。

### 界面与日志

- 修复首页统计需要退出重进才能刷新的问题，返回首页或切换账号后刷新数据。
- 状态栏显示当前执行模块、本轮收取能量和当日收取能量。
- 配置字段页新增搜索；选填编辑页增加全选、反选和取消选择，并完善次数范围校验。
- 好友统计页新增搜索和更清晰的记录展示。
- 运行日志按模块标记，主要记录执行过程；收取、领奖、兑换等结果进入对应的森林／庄园／金豆／其他分类日志。
- 拼图截图移到 `.nomedia/puzzle/` 下，旧目录自动迁移，避免图片出现在相册中。
- 修复拼图纹理扫描超时后的错误兜底拖动；识别不可信时停止自动拖动，扩充真实截图回归样本。
- 异常统计补充错误码与描述，便于定位失败原因。

### 配置保存与兼容

- 修复配置保存可能覆盖未知字段、丢失其他进程修改，以及配置读取失败后误写默认值的问题。
- 每次覆盖配置前保存同目录的 `config_v2.prev.json` 即时快照，按天滚动备份也改为在写入前执行。
- 修复时间类配置按错误单位截断、未修改却提示保存成功，以及恢复默认配置时的异常。
- 加强 HTTP 接口令牌校验，未配置令牌时拒绝请求。
