# 说明文件索引（Agent / 开发者统一入口）

所有说明文件都在 `docs/` 下（2026-09-22 把 `doc/` 合并进来：`MyFix.md`、`GR-Sync.md`、`每日异常反馈.txt`、`INDEX.md` 共 4 个文件搬入）。
日常任务只读「必读」，其余按任务按需读对应章节，不要全量通读。

## 必读（每次任务开工前）

| 文件 | 内容 | 规模 |
|---|---|---|
| `AGENTS.md`（根目录） | Agent 入口：合并必查三项、回归命令、分支、关键架构、代码地图、合并速览 | 约 100 行 |
| `docs/MyFix.md` | 硬性规则（GMT+8、JSON 创建、JSON 读取、独立进程禁引 `ApplicationHook`、保留 `GeminiAI`）+ GR `MyUtils` 背景附录 | 约 40 行 |

## 按需读

| 文件 | 何时读 | 说明 |
|---|---|---|
| `CHANGELOG.md`（根目录） | 查历史决策/某次合并取舍时 | 很大（约 1100 行）。只读最近约 80 行，或按关键字 grep，不要全读 |
| `docs/使用说明.md` | 改用户可见行为（安装、目录、日志类目、黑名单、AI 答题、备份、FAQ）时读相关节 | 用户手册，约 370 行 |
| `docs/配置项说明.md` | 增删改 `ModelField` 配置项时 | 由 `docs/tools/gen_fields.ps1` 从源码自动生成，改完源码配置项后用该脚本重新生成；与实现不一致时以源码为准 |
| `docs/GR-Sync.md` | 从 GR2026 移植代码时 | 2026-09-12 的静态审计（文件异同、SO 现状、可删候选），部分结论已过时（如版本伪装已删除），当前结论以实际源码为准 |
| `docs/每日异常反馈.txt` | 收到用户发来的 `rpc-failures.日期.账号.json` 异常统计时 | 每日异常回传的操作流程与分析要求 |
| `docs/庄园奖励领取.md` | 跟进庄园道具/美食领取问题时 | 需求、已确认事实、三批改动、待确认的美食 awardType 真值 |
| `README.md`（根目录） | 了解项目总览、功能分组、技术栈时 | 含 9 分组模块表与文档表 |
| `docs/tools/gen_fields.ps1` | `docs/配置项说明.md` 过期时 | 配置项说明生成脚本 |

## 写作约定

- 长期规则只写 `docs/MyFix.md`；每次合并/修 bug/加功能记 `CHANGELOG.md`（顶部一行摘要 + 文末详细记录），不写回 `MyFix.md`。
- 用户手册、开发者规则都在 `docs/` 下新增文件，不要另起目录。
